# Word Counter App

A browser-based word and character counter built by Abdul Hameed using React, Vite, and Tailwind CSS. Type or paste text to see counts update as you edit.

[Open the live Word Counter](https://word-counter-by-abdulhameed.vercel.app/)

## Run locally

Install dependencies with `npm ci`, then start Vite with `npm run dev`. Use `npm run build` to generate the production build.
